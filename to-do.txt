Feature draft:
1. Alternative meal preference. User can choose meals for which he wants an alternative. It can be changed at will, but cannot be done on per meal basis. In other words it will be an automated system and not 'opt-in' per meal basis. Now for this to work, menu(s) must be fixed first. The managers should be able to add a new menu anytime.

2. Review System. Users can rate any meal(s) from 0 to 5 stars. The managers can see the reviews and insights.

3. Manager can mark an upcoming meal as featured meal, which will be highlighted on top of Homepage and user dashboard. User will get a an email notification

4. Add a new route to manager dashboard to check admin actions regarding meal registrations, with stats like total number of late cancellations per month, and the users with most late actions

5. Add admin action statistics to the monthly finalization records

6. Add a full fledged inventory management system, tracking and linking key items like meat, eggs, fish etc directly to expenses
